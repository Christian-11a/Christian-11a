# Hi, I'm Christian

Computer Science student focused on frontend web development, growing toward full-stack.

I build responsive websites and practical browser tools with React, Next.js, TypeScript, and Tailwind CSS. My work explores accessible interactions, thoughtful layouts, and useful features that run in the browser.
